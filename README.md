# Zhishen Sun's academic homepage

Static bilingual academic homepage for Zhishen Sun (孙志深).

## GitHub Pages

Publish this repository from the `main` branch and the `/(root)` directory in **Settings → Pages**. The homepage address will be `https://szs777.github.io/` once the deployment succeeds.

The root `index.html`, `styles.css`, `script.js`, `.nojekyll`, and `assets/` folder are the complete public website. No build command or external runtime is required.

The canonical local source is the sibling `dist/` folder in the original `personal-website` project. Copy its contents here after future edits while retaining `.nojekyll`.
